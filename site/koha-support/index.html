      This GitHub Pages version uses Google's popup authorization. It does not use a callback URL or client secret. Read-only permission can cover your accessible spreadsheets; this dashboard fetches only the selected spreadsheet tab.

      Sheet fields & report accuracy

      “Test” is displayed as Library / institute. Timestamp is the reported date; Assigned Date and Time is the assignment date. Blank status is counted as Needs triage. Resolved, Completed, and Closed count as resolved.

      Add a Resolution Date column to enable closure-date reporting. Missing Case IDs use sheet row references. Historical library and ownership reflect current values; reopen history is not available.

      Connection lifecycle

      Google access tokens expire. Use Connect with Google again when prompted. Your Google connection is shared across this hub and its open dashboard tabs. Use the hub to switch dashboards without losing the connection. Disconnect signs out every connected dashboard. Tokens stay in shared browser memory; no token is stored on disk. Closing all hub and dashboard tabs ends the shared session. No unattended background reporting runs on GitHub Pages.
